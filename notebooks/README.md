# Notebooks

This directory is reserved for exploratory notebooks used during the LeafSignal AI learning workflow.

Notebooks may be useful for inspecting sample images, exploring dataset quality, reviewing model outputs, and documenting experiments during early development. Reusable application logic should remain in `src/leafsignal` so it can be tested, imported, and maintained outside a notebook environment.

Do not store credentials, secrets, API keys, Azure subscription details, or personal information in notebooks. Clear large outputs before committing notebooks so the repository stays reviewable and lightweight.
