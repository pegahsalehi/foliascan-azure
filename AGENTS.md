# Instructions for Coding Agents

- Inspect existing files before editing.
- Make small and focused changes.
- Do not modify unrelated files.
- Never hard-code credentials, tokens, API keys, Azure subscription IDs, or other secrets.
- Use `pathlib` for filesystem paths.
- Add type hints to public functions.
- Add or update tests when behavior changes.
- Run relevant tests and quality checks.
- Report all commands run and their results.
- Explain important technical decisions.
- Ask before adding a major dependency or framework.
- Do not create Azure resources unless explicitly requested.
- Do not download large datasets unless explicitly requested.
- Do not commit or push changes unless explicitly requested.
- Do not hide, disable, or delete failing tests merely to make checks pass.
